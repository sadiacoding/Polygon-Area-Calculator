# Polygon Area Calculator 📐

A simple Python project to calculate the area of different polygons using mathematical formulas. This calculator helps users find polygon areas quickly by entering required dimensions.

## Features ✨
- Calculate polygon area
- User-friendly input
- Fast and accurate calculations
- Supports multiple polygon shapes (if applicable)
- Beginner-friendly Python project

## Technologies Used 🛠️
- Python 3

## How It Works ⚙️
1. Run the program
2. Enter polygon details (sides, coordinates, etc.)
3. The calculator computes and displays the area

## Installation 🚀

Clone the repository:

```bash
git clone <your-github-repo-link>
```

Go to project folder:

```bash
cd Polygon-Area-Calculator
```

Run:

```bash
python main.py
```

## Example Output 📌

```text
Enter polygon vertices:
(0,0), (4,0), (4,3)

Area = 6.0
```
